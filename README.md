# Youssef Nasser - Personal Portfolio Website

A personal portfolio website highlighting projects, coursework, software skills, and background in Mathematics and Computer Science.

## 🚀 Live Demo
Visit the live website at: [yoyonasser2023.github.io](https://github.com/)

## 🛠️ Built With
* **HTML5 & CSS3** - Custom dark mode styling, typography, and responsive grid layouts.
* **JavaScript (ES6)** - Interactive tabs, canvas animation sketches, and theme motion.
* **GSAP & ScrollTrigger** - Smooth transitions and scroll animations.

## 📂 Project Features
* **Interactive Panels**: Switch seamlessly between About, Courses, Work, Projects, Skills, and Contact.
* **Canvas Sketches**: Live visual simulations for key projects (Gym Management System, ESP32 Radar, ERD Query Path, Newton-Raphson, Feedback Analytics).
* **Responsive Design**: Mobile-friendly layout with burger menu navigation.
